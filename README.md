# Smart Expense Tracker

## Problem Statement
Many people find it difficult to monitor their monthly spending. Smart Expense Tracker accepts monthly income and expenses, calculates the remaining balance, and warns the user when expenses are high.

## Features
- Calculates remaining balance
- Detects overspending
- Displays financial status
- Simple Java console application

## Technologies
- Java
- Git
- GitHub

## Run
javac -d out src\Main.java
java -cp out Main
